# derbyaqua
Данные: база данных ФАО по мировому выращиванию аквакультуры.

Определения и ограничения: В файле aqua_ddl.sql ddl-структура базы данных apache derby embedded (последняя версия 10.17.1.0) с описанием контента в комментариях. В папке /CSV лежат .csv дампы таблиц этой базы данных, включая две основных таблицы данных TSD_AQUACULTURE_VALUE (стоимость) и TSD_AQUACULTURE_QUANTITY (вес), остальные таблицы либо описательные списки REF_ либо реляционные REL_. Поля, не описанные комментариями в DDL - не имеют никакого значения и игнорируются (за исключением одинаковых полей описанных один раз за все аналоги). В базе много полей с именованиями на языке отличном от английского - они игноруются, используются только поля _EN (английский язык). SQL-запросы создаются в диалекте Apache Derby (обязательно), диалект Derby является крайне ограниченным по сравнению с современным SQL и при этом обязателен для доступа к базам derby, поэтому надо учитывать тонкости и ограничения диалекта.
Вывод делается без дополений в данные базы данных, as is, имена стран такие как в базе, виды как в базе, без изменений и дополнений, если не указано обратное.
Важно, данные придется формировать учитывая группировку видов REF_YEARBOOK_GROUP, с таким расчетом, что группа этого списка ID 00000001 NAME_EN "All aquatic organisms" - вообще игнорируется, она логически является суммой оставшихся трех, но ее состав не описан и не считается в базе и REL-таблице соответствия, а список видов из группы с ID 00000004 NAME_EN "Other aquatic animals & products" - исключается из расчетов и запросов намеренно, вроде группы "прочих", таблицы формируются суммой данных по видам, входящим в группы ID 00000002 и ID 00000003 (рыбы и тд + водоросли) этой группировки.
Под строками "К" и "С" понимается количество в тоннах и стоимость в тыс.долларов, данные берущиеся из соответственно основых таблиц данных TSD_AQUACULTURE_QUANTITY и TSD_AQUACULTURE_VALUE.
