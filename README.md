# derbyaqua
Данные: база данных ФАО по мировому выращиванию аквакультуры.

Определения и ограничения: В файле aqua_ddl.sql ddl-структура базы данных apache derby embedded с описанием контента в комментариях. В папке /CSV лежат .csv дампы таблиц этой базы данных, включая две основных таблицы данных TSD_AQUACULTURE_VALUE (стоимость) и TSD_AQUACULTURE_QUANTITY (вес), остальные таблицы либо описательные списки REF_ либо реляционные REL_. Поля, не описанные комментариями в DDL - не имеют никакого значения и игнорируются (за исключением одинаковых полей описанных один раз за все аналоги). В базе много полей с именованиями на языке отличном от английского - они игноруются, используются только поля _EN (английский язык). SQL-запросы создаются в диалекте Apache Derby (обязательно), диалект Derby является крайне ограниченным по сравнению с современным SQL и при этом обязателен для доступа к базам derby, поэтому надо учитывать тонкости и ограничения диалекта.
Вывод делается без дополений в данные базы данных, as is, имена стран такие как в базе, виды как в базе, без изменений и дополнений, если не указано обратное.
Важно, данные придется формировать учитывая группировку видов REF_YEARBOOK_GROUP, с таким расчетом, что группа этого списка ID 00000001 NAME_EN "All aquatic organisms" - вообще игнорируется, она логически является суммой оставшихся трех, но ее состав не описан и не считается в базе и REL-таблице соответствия, а группа с ID 00000004 NAME_EN "Other aquatic animals & products" - исключается из расчетов и запросов намеренно, вроде группы "прочих". То есть все без исключения таблицы формируются только суммой данных по видам, входящим в группы ID 00000002 и ID 00000003 (рыбы и тд + водоросли) этой группировки.

1. Проанализировать структуру базы;
2. Создать SQL-запросы в диалекте derby, необходимые для построения финальных таблиц;
3. Сформировать python программу для получения Excel-файла (результата работы) где лист = таблица.
